Claude Code · 状态带配色方案

位置：输入框上方保持不变（AbovePrompt）；字段保持现状： 模型 / effort / ctx / ↑ / ↓ / cache / t/s；窄屏折成两行。
模型与 effort 沿用现有蓝色并加粗，本次只给 ctx 及其后的数值上色。主色：橙 / 黄 / 绿 / 白。
橙 #FFA94D 黄 #FFD43B 绿 #51CF66 白 #F5F7FA 模型（不变）#4C9AFF 浅色主题：橙 #D9480F / 黄 #9A6700 / 绿 #2B8A3E
