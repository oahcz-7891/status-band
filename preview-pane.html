Claude Code · /band 选择器预览

/band 不开侧边面板、不弹 AskUserQuestion，而是把选择器作为 inline 面板画在输入框正上方 （输入框正上方），风格与 /effort 的菜单一致：标题、三行编号选项、当前项加粗。
打开时接管键盘：上下键移动、Enter 选中；也可直接按 1 / 2 / 3。Esc 关闭且不改状态，再按一次 /band 同样关闭。

说明：选择器是一个 Pane（inline，rows 设为内容高度），打开时 focus: true 接管键盘：↑↓ 移动焦点、Enter 选中、Esc 关闭（closeOnEscape）。 三行是 Button（plain）带 hotkey「1 / 2 / 3」，当前项 autoFocus。 没有界面时 $.ui.open 返回 isPlaced: false，命令只回一行原因，状态不变。
也可以跳过选择器：/band show、/band hide、/band color、/band gray。
